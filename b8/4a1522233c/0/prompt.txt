# Landesweite Restructuring — Implementation Plan

## Context
The user wants exercises to support "Landesweite" (state-wide) queries organized by Bundesland (OE1-OE9). Currently repeaters are a flat list with no Bundesland association. The exercise setup needs restructuring so admins can select participating Bundesländer, see all repeaters per Bundesland, assign operators per repeater, and add custom repeaters/frequencies during setup. The repeater list must be expanded to a comprehensive Austrian list sourced from OEVSV data.

## Step 1: Schema Changes
**File:** `server/src/db/schema.ts`

- Add `bundesland_code TEXT REFERENCES bundeslaender(code)` to `repeaters` table
- Add index `idx_repeaters_bundesland ON repeaters(bundesland_code)`
- Add migration for existing databases: check PRAGMA table_info and ALTER TABLE if column missing
- Add `is_custom INTEGER DEFAULT 0` to `repeaters` (for user-added repeaters during exercise setup)

## Step 2: Add API Endpoint for Creating Repeaters
**File:** `server/src/routes/repeaters.ts`

- Add `POST /api/v1/repeaters` — create a custom repeater (short_name, frequency_mhz, bundesland_code, type, etc.)
- Add `GET /api/v1/repeaters?bundesland_code=08` — filter repeaters by Bundesland
- Add `GET /api/v1/repeaters?type=simplex` — filter simplex frequencies

## Step 3: Expand Seed Data with Comprehensive Austrian Repeaters
**File:** `server/src/db/seed.ts`

- Fetch/compile comprehensive repeater list from OEVSV (repeater.oevsv.at)
- Organize all repeaters by Bundesland code (01-09)
- Each repeater gets: short_name, site_name, band, callsign, frequency_mhz, offset_mhz, ctcss_hz, type, bundesland_code
- Add default simplex frequencies: 145.500, 145.525, 145.550 MHz (type='simplex', no bundesland_code)
- Keep existing Einstiegspunkte for Magdalensberg linked repeater

## Step 7: Migration Safety
**File:** `server/src/db/schema.ts`

Add migration for `bundesland_code` and `is_custom` columns on repeaters table:
```
const repCols = db.prepare("PRAGMA table_info(repeaters)").all();
if (!repCols.some(c => c.name === 'bundesland_code')) {
  db.exec("ALTER TABLE repeaters ADD COLUMN bundesland_code TEXT REFERENCES bundeslaender(code)");
}
if (!repCols.some(c => c.name === 'is_custom')) {
  db.exec("ALTER TABLE repeaters ADD COLUMN is_custom INTEGER DEFAULT 0");
}
```
