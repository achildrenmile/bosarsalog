# Sonderauswertung (Special Reports) — Date Range Aggregated Stats

## Context
The app has per-exercise reports at `/exercises/:id/reports`. The user wants a new report type that accumulates data across a date range (quarterly, yearly, custom). It should show the same visualizations (map, charts, tables) but aggregated across all exercises in the range, with the timespan displayed at the top. Accessible via a dedicated nav link.

## Changes

### 1. Server: Aggregated Stats Endpoint
**`server/src/routes/reports.ts`** — replace placeholder

New endpoint: `GET /api/v1/reports/stats?from=YYYY-MM-DD&to=YYYY-MM-DD`

- Fetch exercises in date range, collect their IDs
- Run the same 5 SQL queries as `exercises/:id/stats` but with `WHERE sr.exercise_id IN (?,?,...)` instead of single exercise filter
- `totalParticipants`: COUNT(DISTINCT operator_id) — deduplicates across exercises
- `totalReports`, `perRepeater`, `bezirkStats`, `blStats`, `participants`: same pattern
- Returns: `{ exercises[], stats: { totalParticipants, totalReports, perRepeater[], bezirkStats[], blStats[], participants[] } }`

### 2. Shared Types
**`client/src/types/stats.ts`** — NEW

Extract interfaces from ReportsPage.tsx (lines 16-54): `BezirkStat`, `BlStat`, `Participant`, `RepeaterStat`, `Stats`. Both pages import from here.

### 3. New Page
**`client/src/pages/AggregatedReportsPage.tsx`** — NEW

- Quick-select buttons: Q1, Q2, Q3, Q4, Jahr (current year)
- Two date inputs (Von / Bis) for custom range
- Timespan header: "01.01.2026 – 31.03.2026 · 12 Übungen"
- Summary cards: Teilnehmer (unique), Rapporte, Übungen, Ø Teilnehmer/Übung
- Collapsible exercise list (date, name, individual counts)
- AustriaMap, bar chart, pie chart, bezirk table, participant list (same as ReportsPage)

### 4. Route + Navigation
