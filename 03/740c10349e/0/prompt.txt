## Context
Issue #12 requests: larger headings, more spacing between blocks, larger text, and better menu accessibility. Bootstrap was suggested but is not recommended — the project already uses Tailwind CSS v4 and switching would require a massive rewrite for no clear benefit. ## Current Problems
- **Headings too small**: h1 ranges 16-24px (inconsistent), h2/card headers only 12-14px
- **Text too small**: Heavy use of `text-xs` (12px) for labels, form inputs, nav, tables
- **Tight spacing**: Data entry uses `space-y-2`, cards use `p-3 sm:p-4`
