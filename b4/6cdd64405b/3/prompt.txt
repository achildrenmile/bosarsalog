# Issue #8: Download Auswertung — Server-seitiges PDF

## Context
"Download Auswertung komplett" nutzt `html-to-image` (`toPng()`), das den gesamten DOM klont — inkl. SVG-Karte, Chart.js-Diagramme, große Tabellen. Bei umfangreichen Auswertungen crasht der Browser (500MB+ RAM, Main Thread blockiert). Lösung: PDF-Generierung auf dem Server mit PDFKit (pure JS, kein Chromium nötig, läuft auf Alpine).

**Scope:** Nur die "Download Auswertung komplett"-Buttons auf beiden Seiten werden auf PDF umgestellt. Einzelne Chart-Downloads (Karte, Balken, Torte) bleiben als PNG via html-to-image.

## Ansatz: PDFKit (pure JavaScript)

- Kein Chromium/Puppeteer nötig → kein Dockerfile-Umbau
- SVG-Pfade der Austria-Karte können direkt mit PDFKit gezeichnet werden
- Bar-/Pie-Charts werden mit PDFKit-Zeichenprimitiven (Rechtecke/Kreissegmente) nachgebaut
- Tabellen als strukturierter Text

## Änderungen

### 1. Dependency hinzufügen
```
cd server && npm install pdfkit @types/pdfkit
```

### 2. Neue Datei: `server/src/services/pdf.ts`

Shared PDF-Generator mit Helper-Funktionen:

- `renderHeader(doc, title, subtitle)` — BOS-ARSA Branding (dunkelblaue Leiste, Titel, Slogan)
- `renderSummaryCards(doc, stats, exerciseCount?)` — Teilnehmer/Rapporte/Übungen Zahlen
- `renderPerRepeater(doc, perRepeater)` — Repeater-Übersicht Grid
- `renderExerciseTable(doc, exercises)` — Übungsliste (nur aggregiert)
- `renderAustriaMap(doc, blStats)` — SVG-Pfade aus AustriaMap.tsx, Farben nach Teilnehmerzahl
- `renderBarChart(doc, chartData)` — Balkendiagramm mit Rechtecken
- `renderPieChart(doc, chartData)` — Tortendiagramm mit Kreissegmenten
- `renderBezirkTable(doc, bezirkStats)` — Bezirk/BL Tabelle mit Hierarchie
- `renderBlTable(doc, blStats)` — Bundesland-Tabelle (Fallback ohne Bezirke)
- `renderParticipants(doc, participants)` — Teilnehmer-Liste
- `renderFooter(doc)` — "oeradio.at · bosarsa.oeradio.at"

Austria-Karte: SVG-Pfaddaten aus `AustriaMap.tsx` extrahieren und als Konstante in pdf.ts ablegen. PDFKit zeichnet die Pfade mit `doc.path(d).fill(color)`. Farblogik (Heatmap nach Teilnehmern) wird 1:1 übernommen.

### 3. Neue Datei: `server/src/routes/pdf.ts`

Zwei Endpunkte:

**GET `/api/v1/pdf/reports?from=...&to=...&types=...`** — Aggregierte Auswertung
- Nutzt gleiche DB-Queries wie `reports.ts:/stats`
- Ruft PDF-Generator auf mit exercises + stats
- Response: `application/pdf` mit Content-Disposition

**GET `/api/v1/pdf/exercises/:id`** — Einzel-Übung Auswertung
- Nutzt gleiche DB-Queries wie `exercises.ts:/:id/stats`
- Ruft PDF-Generator auf mit exercise + stats
- Response: `application/pdf` mit Content-Disposition

### 4. Route registrieren: `server/src/index.ts`

```ts
import { pdfRouter } from './routes/pdf.js';
app.use('/api/v1/pdf', authMiddleware, pdfRouter);
```

### 5. Client: `AggregatedReportsPage.tsx`

- `downloadFullPage()` ersetzen: statt `toPng()` → `fetch('/api/v1/pdf/reports?from=...&to=...&types=...')` + Blob-Download
- Dateiname: `BOS-ARSA_Auswertung_{from}_{to}.pdf`
- `toPng`-Import kann bleiben (wird für einzelne Chart-Downloads weiter genutzt)

### 6. Client: `ReportsPage.tsx`

- `downloadFullPage()` ersetzen: statt `toPng()` → `fetch('/api/v1/pdf/exercises/${id}')` + Blob-Download
- Dateiname: `BOS-ARSA_Auswertung_{date}.pdf`
