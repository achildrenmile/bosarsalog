# Simplex Bezirke: BL-Auswahl konfigurierbar machen

## Context
Aktuell zeigt die Simplex-Bezirk-Gruppierung immer alle 9 BLs (OE1-OE9) hardcoded. Der User will pro Übung auswählen können, welche Bundesländer in der Simplex-Gruppierung angezeigt werden.

## Änderungen

### 1. Schema Migration — `server/src/db/schema.ts`
Nach der `simplex_bezirke`-Migration neue Spalte:
```sql
ALTER TABLE exercises ADD COLUMN simplex_bl_codes TEXT
```
Speichert komma-separierte BL-Codes, z.B. `"06,08"`. NULL = alle 9 BLs.

### 2. API — `server/src/routes/exercises.ts`
- **GET list**: `e.simplex_bl_codes` zum SELECT hinzufügen
- **POST**: `simplex_bl_codes` akzeptieren + einfügen
- **PATCH**: `simplex_bl_codes` als update-Feld (gleicher Pattern wie `organisator`)

### 3. ExerciseSetupPage — `client/src/pages/ExerciseSetupPage.tsx`
Wenn `simplex_bezirke` aktiviert: unterhalb des Toggles ein BL-Grid anzeigen (gleicher Stil wie Bundesländer-Grid Zeile 362, aber kompakter). Klick toggelt BL-Code in `simplex_bl_codes`. PATCH bei jeder Änderung.

Beim erstmaligen Aktivieren des Toggles: alle 9 BL-Codes setzen.

### 4. ExercisePage — `client/src/pages/ExercisePage.tsx`
Neuen Prop `simplexBlCodes={exercise.simplex_bl_codes || ''}` an LandMode durchreichen.

### 5. LandMode — `client/src/components/LandMode.tsx`
- Props: `simplexBlCodes?: string` hinzufügen
- `activeBlCodes`: wenn `simplexBlCodes` nicht leer → `simplexBlCodes.split(',')`, sonst alle 9 (Fallback)

### 6. Changelog — `CHANGELOG-2026-02-24.md`
Issue #2 Beschreibung um BL-Auswahl erweitern.
