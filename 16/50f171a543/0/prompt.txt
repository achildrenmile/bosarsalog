# Plan: Designanpassungen (Issue #12)

## Context
Issue #12 requests: larger headings, more spacing between blocks, larger text, and better menu accessibility. Bootstrap was suggested but is not recommended — the project already uses Tailwind CSS v4 and switching would require a massive rewrite for no clear benefit. Instead: systematic Tailwind class upgrades across all components.

## Current Problems
- **Headings too small**: h1 ranges 16-24px (inconsistent), h2/card headers only 12-14px
- **Text too small**: Heavy use of `text-xs` (12px) for labels, form inputs, nav, tables
- **Tight spacing**: Data entry uses `space-y-2`, cards use `p-3 sm:p-4`
- **Nav accessibility**: `text-xs sm:text-sm` nav links, no ARIA labels

## Size Upgrades (old → new)

| Element | Old | New |
|---------|-----|-----|
| **h1 (page titles)** | `text-base sm:text-xl` | `text-xl sm:text-2xl` |
| **h2 (card/section headers)** | `text-xs sm:text-sm` | `text-sm sm:text-base` |
| **Navbar links** | `text-xs sm:text-sm` | `text-sm sm:text-base` |
| **Mobile menu links** | `text-xs` | `text-sm` |
| **Form labels** | `text-xs` | `text-sm` |
| **Table headers** | `text-xs` | `text-sm` |
| **Table cells** | `text-xs sm:text-sm` | `text-sm` |
| **Buttons** | `text-xs sm:text-sm` | `text-sm` |
| **Form inputs (data entry)** | `text-xs` | `text-sm` |

## Spacing Upgrades (old → new)

| Element | Old | New |
|---------|-----|-----|
| **Main page blocks** | `space-y-4` | `space-y-6` |
| **Card padding** | `p-3 sm:p-4` | `p-4 sm:p-5` |
| **Main content padding** | `p-2 sm:p-4` | `p-3 sm:p-5` |
| **BundMode/LandMode sections** | `space-y-2` | `space-y-3` |
