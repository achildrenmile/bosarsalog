# Issue #2: Simplex Bezirk Grouping Toggle

## Context
GitHub Issue #2 — "Option Bezirkskenner in Simplex Frequenzen anzuzeigen". Currently, simplex frequencies in LandMode render as flat lists (FlatReportRow) without Bezirk grouping, because simplex repeaters have `bundesland_code=null` so `repBezirke` is always empty. The user wants an optional per-exercise toggle to group simplex frequency reports by Bundesland → Bezirk, matching how repeater reports are structured. The toggle must be off by default since "nicht überall braucht man bundesland bezirk."

### 5. LandMode — Conditional Grouping
**`client/src/components/LandMode.tsx`**

- Add `simplexBezirke` to Props interface (line 18-25)
- Derive `activeBlCodes` from `Object.keys(repeatersByBl)` — these are the Bundesländer that have active repeaters
- In simplex rendering section (lines 340-349): when `simplexBezirke` is true, instead of just listing simplex repeaters flat, group them by active Bundesland with BL sub-headers
- In `renderRepeaterCard` (line 209): when `rep.type === 'simplex'` AND `simplexBezirke` is true:
  - Set `repBezirke` to all bezirke from all active Bundesländer (not just `rep.bundesland_code`)
  - This makes the card use BezirkRow components instead of FlatReportRow
  - Group bezirke by BL with sub-headers for each BL

Implementation detail for `renderRepeaterCard`:
```tsx
// Current: repBezirke is empty for simplex → FlatReportRow
const repBezirke = bezirke.filter(b => b.bundesland_code === rep.bundesland_code);

// New: when simplex_bezirke enabled AND this is a simplex repeater,
// use bezirke from ALL active Bundesländer
const isSimplexGrouped = simplexBezirke && rep.type === 'simplex';
const repBezirke = isSimplexGrouped
  ? bezirke.filter(b => activeBlCodes.includes(b.bundesland_code))
  : bezirke.filter(b => b.bundesland_code === rep.bundesland_code);
```

When `isSimplexGrouped`, render BL sub-headers within the card:
- Group `repBezirke` by `bundesland_code`
- For each BL group, show a sub-header with BL name, then BezirkRow for each bezirk
- Reports assigned to bezirke in that BL appear in their respective BezirkRow
- Unassigned reports appear in "Sonstige" section at the bottom
